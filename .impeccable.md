# Impeccable Design Context — Warwick Move-In

## Design Context

### Users
Arielle and students like her: an incoming University of Warwick first-year, moving into halls for the first time, weeks out from term start. Used almost entirely on a phone — in a bedroom sorting what's already owned, in a shop comparing two prices, in the car park loading boxes, or packing the night before. A parent sometimes opens a read-only shared view to see progress and log what they've contributed toward the budget. The dominant emotional state is **hurried and slightly anxious logistics**, not leisurely browsing — every screen competes with "I have 20 minutes and a bag to pack."

### Brand Personality
Three words: **tactile, hurried, hopeful.** Tactile — the whole experience is physical (boxes, tape, luggage tags, a manifest pinned to a door), not abstract "shopping app" chrome. Hurried — a countdown-driven checklist, not a leisurely catalogue; density and speed matter more than whitespace for its own sake. Hopeful — first time living away from home is a fresh start, not just an errand; the tone should never feel like a spreadsheet or a compliance form.

### Aesthetic Direction
Reference world: a **shipping manifest / luggage tag / packing label**, not a generic SaaS dashboard or a "cozy lifestyle" storefront. Previous pass used a torn-ticket-stub + kraft-paper + oxblood-red identity; this pass replaces it entirely rather than tuning it — different structural device (a stamped manifest header, not a ticket stub), different accent (a confident postal/ballpoint ink blue + a sparing marigold "hopeful" highlight, not oxblood-red), different type pairing.

Anti-references: warm cream background + terracotta accent + serif display (the generic "AI redesign" default); identical rounded SaaS cards with soft grey shadows repeated for every item; a tracked-out all-caps eyebrow label over every section; anything that reads as a spreadsheet or admin panel.

Both light and dark theme, switching on system preference (`prefers-color-scheme`), each theme's palette derived independently (not one palette with inverted lightness) so dark mode still reads intentional at 9pm in a dorm room, not just "light mode inverted."

### Design Principles
1. **One structural device, reused with restraint.** The manifest/label motif (stamped header, perforated tear line, manifest-style key-value rows) is the signature — use it once per screen at most, never as decoration on every card.
2. **Density serves speed, but hierarchy prevents clutter.** This is a checklist app used in a hurry — don't pad it into whitespace for its own sake — but every list needs a stronger scan path than "row after identical row" (category icons, collapsing sections, real product imagery instead of letter-swatches).
3. **Real materials over illustration.** Product photography and real retailer marks (fetched from live sources) instead of flat letter-in-a-box placeholders — the physical-shopping feel is part of the brand, not incidental.
4. **Never let floating chrome eat content.** Any fixed/floating element (nav, agent button, toasts) must reserve real layout space — this was a literal shipped bug in the previous pass and is now a hard rule.
5. **Confidence in one accent, not several.** Ink-blue carries primary action and emphasis; marigold is reserved for the "hopeful" moments (a completed section, a good deal found) — never both competing on the same element.
